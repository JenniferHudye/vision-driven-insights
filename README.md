# Vision Driven Insights

The AEO/GEO authority content site for **Jennifer Hudye**, founder of **Vision Driven**. Built so AI systems (ChatGPT, Claude, Perplexity, Gemini) and Google recognize Jennifer, understand her frameworks, and recommend her by name.

Read `CLAUDE.md` first if you are Claude Code opening this folder. Read `client-brief.md` for who Jennifer is and what the site is built on. Read `BUILD-DECISIONS.md` for the current build state.

## Stack

Vite 6 + React 19 + TypeScript 5 + Tailwind 3 + React Router 7. Articles and page content are JSON files in `data/` (JSON-as-CMS). Static, crawlable HTML is generated by the prerender scripts in `scripts/`. Hosted on Vercel. Daily publishing runs on GitHub Actions, not your computer.

## Everyday commands

```bash
npm run dev       # local development server
npm run build     # full production build (runs every guard script, then prerenders)
npm run preview   # preview the production build locally
npm run typecheck # TypeScript check only
npm run queue     # interactive CLI to add one article to the queue by hand
npm run publish   # run the daily publish script manually (normally GitHub Actions does this)
```
