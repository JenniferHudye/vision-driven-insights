# Social Proof Audit (quarterly)

Checks whether the Recommendation layer (why AI should trust Jennifer enough to recommend her) is still current.

- [ ] Are all testimonials in `data/testimonials.json` shown with full attribution (name, company, situation, outcome)? Any vague ones to replace with a specific one?
- [ ] Any new client wins to add as testimonials or full case studies? (`data/testimonials.json` and `data/case-studies.json`)
- [ ] Any new media features, podcast appearances, or citations since last quarter? Add to `data/press.json`.
- [ ] Is `data/trusted-by.json` current? Any names to add, or any that need permission re-confirmed?
- [ ] Do the same top 5 proof points (companies guided, key testimonials, the Cameron Herold partnership) show up consistently on this site AND on visiondrivenglobal.com AND on LinkedIn AND everywhere else Jennifer is active? Consistency across platforms is itself a trust signal AI weighs.
- [ ] Any awards, certifications, or recognitions to add to `data/awards.json`?
