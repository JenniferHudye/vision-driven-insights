# Reputation Audit (quarterly)

Checks whether the Reputation layer (what AI knows Jennifer stands for) is still accurate and current.

- [ ] Are all named frameworks in `data/frameworks.json` still accurate? Any new ones to name and add?
- [ ] Has Jennifer had any new podcast appearances, articles, or speaking engagements since last quarter? Add them to `data/press.json` and `data/speaking.json`.
- [ ] Is the distinctive POV on the About page (and in `config/voice-profile.md`) still what Jennifer actually believes? If her thinking has evolved, update it everywhere it's referenced.
- [ ] Do the case studies on `/case-studies` still clearly link a named framework to a measurable outcome?
- [ ] Run the queries in `docs/AI-SURFACING-CHECK.md` (ChatGPT, Claude, Perplexity, Gemini) and screenshot the answers. Compare to last quarter's screenshots: is Jennifer showing up more, less, or the same?
- [ ] Spot-check 3 live articles: do they still sound like Jennifer? Any drift from the voice profile?
